# Spaced Monitor 0.1.9

The top bar now has an About button whose dialog reports the installed package
version. This makes support screenshots and bug reports identify the exact build
without requiring a terminal.

Card focus now uses the same deliberate gesture in both directions: double-click
a card for its full-window detailed view, then double-click it again to return.
A stray single click no longer collapses the view.

The Hardware page fits three cards across at the default window size instead of
stretching two oversized cards across each row. The layout remains responsive and
falls back to fewer columns as the window narrows.

End-process buttons now communicate risk before a click. Essential system and
desktop-session processes retain the red X and remain protected by the termination
guard; all other processes use an orange X. A legend and tooltips explain the two
states on both the Overview and Processes tables.
