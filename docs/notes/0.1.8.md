# Spaced Monitor 0.1.8

The 11.26 installed-system review reproduced an exception in the Hardware
page when the sampler returned no supported GPU. This interrupted the update
before Memory, Storage and Network, leaving those sections blank.

The GPU card now shows an unavailable message, clears stale GPU values and
allows all remaining cards to update. A real GTK regression exercises an
initially absent GPU, telemetry appearing, disappearing, and returning, in
both light and dark palettes. It checks the following cards as well as the
GPU state, rather than testing a stand-alone formatter.

Closing the last window now exits the application and stops its worker and
status timer. The window is registered with Gtk.Application, which owns the
event loop; the former second GTK loop could leave an invisible process
running after the window closed. A process-based regression repeats three
real launches and closes, requiring each process to exit cleanly.

The Overview scrolls vertically in small windows instead of clipping graph
labels or hiding the process list. Resizable dividers remain available and
retain their proportions across responsive layout changes. Live GTK checks
verify actual window dimensions, card minimum sizes, label visibility,
scroll reachability and resizing after a divider adjustment.
